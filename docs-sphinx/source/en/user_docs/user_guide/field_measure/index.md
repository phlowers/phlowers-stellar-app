# Field measuring

The **Compute base parameter from terrain measurement** tool turns measurements taken on site
into a sagging parameter at 15°C without wind, which can then be used to create an initial
condition.

Open it from the studio toolbar, then create a new measurement or choose an existing one. The
tool is organised in four tabs, usually filled in order:

```{toctree}
:maxdepth: 1

terrain_data
parameter_calculation
temperature_calculation
parameter_15c_without_wind
```
