Catalog Models
==============

This section documents the catalog models located in ``src/app/core/domain/models/catalog``.
These models represent reference data for cables, chains, attachments, lines, and maintenance teams.

catalog-attachment.model
------------------------

Model for attachment catalog entries (hardware used to attach cables to supports).

catalog-cable.model
-------------------

Model for cable catalog entries (conductors and ground wires).

catalog-chain.model
-------------------

Model for chain catalog entries (insulator chains).

.. js:automodule:: catalog-chain.model

catalog-line.model
------------------

Model for line catalog entries (transmission line types).

.. js:automodule:: catalog-line.model

catalog-maintenance.model
-------------------------

Model for maintenance team catalog entries.
