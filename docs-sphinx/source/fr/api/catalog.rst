Modèles de catalogue
====================

Cette section documente les modèles de catalogue situés dans ``src/app/core/domain/models/catalog``.
Ces modèles représentent les données de référence pour les câbles, chaînes, attaches, lignes et équipes de maintenance.

catalog-attachment.model
------------------------

Modèle pour les entrées du catalogue des attaches (matériel utilisé pour attacher les câbles aux supports).

.. js:automodule:: catalog-attachment.model

catalog-cable.model
-------------------

Modèle pour les entrées du catalogue des câbles (conducteurs et câbles de garde).

.. js:automodule:: catalog-cable.model

catalog-chain.model
-------------------

Modèle pour les entrées du catalogue des chaînes (chaînes d'isolateurs).

.. js:automodule:: catalog-chain.model

catalog-line.model
------------------

Modèle pour les entrées du catalogue des lignes (types de lignes de transport).

.. js:automodule:: catalog-line.model

catalog-maintenance.model
-------------------------

Modèle pour les entrées du catalogue des équipes de maintenance.

.. js:automodule:: catalog-maintenance.model
