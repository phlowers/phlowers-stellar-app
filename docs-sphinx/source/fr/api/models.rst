Modèles de domaine
==================

Cette section documente les modèles de domaine de l'application, situés dans ``src/app/core/domain/models``.

study.model
-----------

Module contenant le modèle Study représentant une étude de ligne électrique.

.. js:automodule:: study.model

section.model
-------------

Module contenant le modèle Section représentant une section de ligne électrique.

.. js:automodule:: section.model

support.model
-------------

Module contenant le modèle Support représentant une structure de support de ligne de transport.

.. js:automodule:: support.model

charge.model
------------

Module contenant le modèle Charge représentant les conditions de charge sur la ligne.

.. js:automodule:: charge.model

user.model
----------

Module contenant le modèle User pour les informations utilisateur.

.. js:automodule:: user.model

initial-condition.model
-----------------------

Module contenant le modèle InitialCondition pour les conditions initiales de calcul.

.. js:automodule:: initial-condition.model

vtl-and-guying.model
--------------------

Module contenant les modèles VTL et haubanage pour les calculs de charges de tension verticale et de haubanage.

.. js:automodule:: vtl-and-guying.model

proto-v4.model
--------------

Module contenant le modèle Proto V4 pour les structures de données du protocole version 4.

.. js:automodule:: proto-v4.model
