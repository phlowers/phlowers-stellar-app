# Mesure de terrain

L'outil **Calcul du paramètre de base à partir des mesures terrain** transforme les mesures prises sur site
en un paramètre de fléchage à 15 °C sans vent, qui peut ensuite être utilisé pour créer une condition initiale.

Ouvrez-le depuis la barre d'outils du studio, puis créez une nouvelle mesure ou choisissez une mesure existante. L'outil est organisé en quatre onglets, généralement remplis dans l'ordre :

```{toctree}
:maxdepth: 1

terrain_data
parameter_calculation
temperature_calculation
parameter_15c_without_wind
```
