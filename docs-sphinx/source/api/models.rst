Domain Models
=============

This section documents the application's domain models located in ``src/app/core/domain/models``.

study.model
-----------

Module containing the Study model representing a power line study.

.. js:automodule:: study.model

section.model
-------------

Module containing the Section model representing a section of a power line.

.. js:automodule:: section.model

support.model
-------------

Module containing the Support model representing a transmission line support structure.

.. js:automodule:: support.model

charge.model
------------

Module containing the Charge model representing load conditions on the line.

.. js:automodule:: charge.model

user.model
----------

Module containing the User model for user information.

.. js:automodule:: user.model

initial-condition.model
-----------------------

Module containing the InitialCondition model for initial calculation conditions.

.. js:automodule:: initial-condition.model

vtl-and-guying.model
--------------------

Module containing the VTL and guying models for vertical tension loads and guying calculations.

.. js:automodule:: vtl-and-guying.model

proto-v4.model
--------------

Module containing the Proto V4 model for protocol version 4 data structures.

.. js:automodule:: proto-v4.model
